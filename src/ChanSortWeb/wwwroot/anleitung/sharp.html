Sharp & baugleiche Geräte

Viele Fernseher von Sharp, Blaupunkt, Dyon, Changhong, alphatronics, JTC Genesis sowie einige Hisense- und Grundig-Modelle haben dieselbe Technik. Sie exportieren .csv-Dateien plus eine oder mehrere Datendateien.

Senderliste jetzt öffnenZur Anleitung
  1. 1ExportierenSenderliste am Fernseher auf einen USB-Stick kopieren
  2. 2ÖffnenDatei oder Ordner hier im Browser laden
  3. 3BearbeitenSortieren, löschen, umbenennen, Favoriten
  4. 4ZurückspielenGespeicherte Datei auf den Stick und importieren

Welches Gerät hast du?

Typische Modelle: Sharp LC-xxCFE4142E, LC-xxUI7552E, xxBJ1E/xxBJ3E/xxBJ5E; Blaupunkt B40A148TCSFHD; Changhong LED32E2200ST2; Dyon Live 22 Pro, ENTER 32 Pro X; Grundig 24 GHB 5944.

Export im normalen MenüViele Modelle haben im Sender- bzw. Installationsmenü einen Punkt zum Export auf USB.Export im Hotel- oder ServicemenüWenn im normalen Menü kein Export zu finden ist.

Export im normalen Menü

Export auf USB

  1. USB-Stick einstecken.
  2. Im Menü Sender bzw. Installation nach Export, Senderliste kopieren oder USB suchen.
  3. Export starten. Sharp Aquos xxBJ1E und ähnliche haben dafür ein eigenes Untermenü.
Auf dem StickSiehe Tabelle unten.

Export im Hotel- oder Servicemenü

Export auf USB

  1. Hotelmenü: MENU und dann 7906 – oder MENU 4588.
  2. Servicemenü: MENU 1147, MENU 11471147 oder SOURCE 2580.
  3. Dort nur die Import-/Export-Funktion verwenden.
Auf dem StickSiehe Tabelle unten.
  • Ändere im Servicemenü keine anderen Werte – das kann den Fernseher beschädigen.

Was liegt auf dem Stick?

Unsicher? Wähle im Editor einfach den ganzen Ordner vom Stick – das Format wird automatisch erkannt.

DateiWas tun?
DVBS_Program.csv + cvt_database.datOrdner wählen.
DVBS_CHANNEL_TABLE.csv + dtv_cmdb….binOrdner wählen.
MS…_DVBS_CHANNEL_TABLE.csv + MS…_HOTELMODE_TABLE.jsonOrdner wählen.

Zurück auf den Fernseher

  1. Alle Dateien wieder auf den Stick kopieren – bei manchen Modellen (z. B. Sharp xxBJ1E) sind alle vier Dateien für den Import nötig.
  2. Im selben Menü den Import starten.

Tipp: Bewahre eine Kopie der Originaldatei auf. Dann kannst du jederzeit zum alten Stand zurück.

Häufige Probleme

Welche Datei soll ich hochladen?

Am einfachsten den ganzen Ordner – der Editor sucht sich die passenden Dateien selbst.

Hat es bei dir so geklappt? Menünamen unterscheiden sich je nach Modell und Software-Stand. Wenn es bei deinem Gerät anders heißt, schreib uns kurz Modell und Menüweg – wir ergänzen die Anleitung.
