Panasonic: Sender sortieren

Bei Panasonic gibt es besonders viele Varianten: normale Menüfunktion, Hotel-Menü oder einen Code mit vorbereitetem USB-Stick. Nicht jedes Modell lässt sich bearbeiten – unten steht, welche gehen.

  2. 2ÖffnenDatei oder Ordner hier im Browser laden
  3. 3BearbeitenSortieren, löschen, umbenennen, Favoriten
  4. 4ZurückspielenGespeicherte Datei auf den Stick und importieren

Welches Gerät hast du?

Viera-Modelle ohne Android haben ein eigenes Panasonic-Menü (Startbildschirm „my Home Screen“). Android-TV-Modelle haben Google-Apps auf dem Startbildschirm. Die Serie steht in der Modellnummer, z. B. TX-55LX700E.

Viera (ohne Android) – neuere Software

Export auf USB

  1. USB-Stick einstecken.
  2. Menü › Setup › Andere Einstellungen › Senderliste austauschen (bzw. „Channel List Transfer“).
  3. Senderliste exportieren wählen.
Auf dem Sticksvl.bin oder svl.db

Viera – ältere Software (Code-Methode)

Export auf USB

  1. Auf einem USB-Stick bzw. einer SD-Karte (FAT32) eine leere Datei oder einen leeren Ordner mit dem Namen hotel.pwd anlegen.
  2. Stick bzw. Karte in den Fernseher stecken – er fragt nach einem Passwort.
  3. 4850 eingeben, um die Liste auf den Stick zu kopieren.
Auf dem Sticksvl.bin oder svl.db
  • Zum Zurückspielen später 4851 eingeben.

Android TV LS/LX 500–700 (ab 2022)

Export auf USB

  1. MENU › Bild › Bildmodus › Benutzerdefiniert › Kontrast wählen und dann 6× OK drücken – ein verstecktes Menü öffnet sich.
  2. Hotel Menu › Hotel Mode Activate wählen.
  3. Weiter unten TV to USB wählen.
  4. Stick nicht abziehen, auch wenn „Upload OK“ erscheint. Stattdessen über HOME › Benachrichtigungen › USB-Gerät › Auswerfen abmelden.
Auf dem StickOrdnerstruktur mit mnt/vendor/tvdata/database/tv.db – im Editor den ganzen Ordner wählen.
  • Zum Zurückspielen im selben Menü USB to TV wählen.

MX600 / MX700 / MZ800 und Fire-TV-Modelle

Export auf USB

  1. MX600 und ähnliche: Einstellungen › Installation › Satelliten-Einstellungen › Sat-Senderliste › Sat-Senderliste speichern (nur Satellit).
  2. MX700, MZ800: die Senderliste über die Exportfunktion im Sendermenü speichern.
  3. Fire-TV-Modelle (z. B. MXW834): Export über das Sendermenü.
Auf dem Stick.sdx (MX600, Fire TV) bzw. channellist.txt (MX700, MZ800)
  • Der genaue Menüname weicht bei diesen Modellen stark ab – such im Handbuch nach „Senderliste speichern“ bzw. „exportieren“.

Was liegt auf dem Stick?

Unsicher? Wähle im Editor einfach den ganzen Ordner vom Stick – das Format wird automatisch erkannt.

DateiWas tun?
svl.bin / svl.dbViera: direkt hochladen.
…/tv.dbAndroid LS/LX 500–700: ganzen Ordner wählen.
.sdx / channellist.txtMX-Serien, Fire TV: direkt hochladen.
settingsDB_enc.db, channel_list.binJXW600 / JXW800: wird nicht unterstützt (verschlüsselt).

Zurück auf den Fernseher

  1. Bearbeitete Datei an dieselbe Stelle auf dem Stick kopieren.
  2. Gleicher Weg wie beim Export: Senderliste importieren, Code 4851 bzw. USB to TV.

Tipp: Bewahre eine Kopie der Originaldatei auf. Dann kannst du jederzeit zum alten Stand zurück.

Häufige Probleme

Die Sendernamen fehlen im Editor.

Bei analogen Sendern speichern manche Panasonic-Geräte keine Namen. Digitale Sender sollten Namen haben.

Mein Android-Modell (vor 2022) wird nicht erkannt.

Diese Modelle speichern die Liste verschlüsselt. Sie lassen sich leider nicht bearbeiten.

Hat es bei dir so geklappt? Menünamen unterscheiden sich je nach Modell und Software-Stand. Wenn es bei deinem Gerät anders heißt, schreib uns kurz Modell und Menüweg – wir ergänzen die Anleitung.
